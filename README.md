🌾 AI Crop Recommendation System

📌 About the Project

The AI Crop Recommendation System is a Python-based machine learning application that recommends suitable crops based on soil nutrients and environmental conditions.
Developed as part of an Artificial Intelligence and Machine Learning internship with guidance, this project builds on an existing project and uses a Random Forest algorithm to generate crop recommendations through a Streamlit web application.

Features:
- Recommends crops based on soil and climate conditions.
- Uses a trained Random Forest machine learning model.
- Provides a simple, interactive web interface.
- Displays crop predictions based on user inputs.

🌱 Input Parameters
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

🛠️ Technologies Used
- Programming Language: Python
- Machine Learning Algorithm: Random Forest
- Web Framework: Streamlit
- Model Storage: Pickle

📂 Project Structure
- "app.py" – Main application code
- "crop_model.pkl" – Saved machine learning model
- "requirements.txt" – Required Python libraries
